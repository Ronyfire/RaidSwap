# RaidSwap — Frontend

React + Vite + TypeScript + Tailwind CSS. See the [root README](../README.md) for what RaidSwap is and how to run the whole project (backend + database included).

## Scripts

- `npm run dev` — start the dev server (expects the backend on `VITE_API_URL`, see `.env.example`)
- `npm run build` — type-check (`tsc -b`) and build for production
- `npm run lint` — ESLint
- `npm run preview` — preview the production build locally
